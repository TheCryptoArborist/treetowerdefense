# Enemy counterplay · v0.11

New runs now introduce two distinct behaviors alongside the existing termite march and beetle armor. Campaign wave counts, spawn gaps, HP, leak damage, rewards, defender unlocks and purchase prices are unchanged. Seasonal content is still planned.

| Pest | Behavior | Counterplay | Battlefield marker |
| --- | --- | --- | --- |
| Termite | Steady movement | Reliable coverage; splash against clusters | Existing segmented silhouette |
| Beetle | Direct-hit armor | Sustained fire, poison, or Watchtower armor-piercing bolts | Existing armor plates |
| Moth | 20% speed burst for 0.65 seconds every four battle seconds, first burst at age two seconds | Palm slows remain effective; Fastest uses current speed; cover later bends | Two pale trailing streaks during the burst |
| Blight | Recovers 0.6% of maximum health per second after two seconds without a damaging hit; active poison prevents recovery | Overlapping coverage delays recovery; Mushroom suppresses it with poison | A mauve ring and plus marker only while recovering |
| Blight King | Existing boss rules | Damage coverage and slows | Existing boss health display |

The wave sequence teaches armor in wave 2, moth bursts in wave 3, and blight recovery in wave 4. Mushroom becomes available after wave 6. Later scouting calls out target orders, poison and armor-piercing options. Each portrait card now displays its counterplay text, including exact trait rules.

Movement, Fastest targeting and art share the same moth phase calculation. Timers use battle time, so pause, dialogs and hidden-tab pauses freeze them. Reduced motion uses static trait markers without extra animation. Poison damage resolves before recovery; dead blight cannot recover. Healing caps at max HP. Every damaging strike, including splash, chains and Leaf Storm, delays recovery. No extra damage, rewards, purchases or attacks are generated by these markers.

## Saved runs

Optional `enemyRules: 1` identifies a current-rules run. New pests store `behavior: 1`, `bornAt` and `recoverAt`. Existing saves without the rule marker use legacy behavior for living pests and all queued future spawns through the rest of that run. Scouting and wave notices explain the legacy rules. Starting a fresh run enables the new behavior while preserving TREE, permanent growth, stars and earned roster.

Current saves preserve timers on reload, pause and continue. Invalid optional behavior timers fall back to the ordinary pest without discarding funds or growth. The core save version remains 2; all state remains editable development data, not production ownership/payment proof.

Seven new tests cover burst timing, movement/target agreement, regeneration limits, real Palm/Mushroom counters, pause/reload, legacy queued spawns, invalid optional fields and scouting/notices. JavaScript syntax checks pass.

`npm run balance`: all 15 existing strategy simulations complete. Broader mixed Sapling coverage clears Emerald/Sunpetal/Moonlit at 100/100/82 health with zero TREE spent; the earned-roster campaign test also reaches all eight unlocks without TREE purchases. A fixed simulation is not a prediction of human play. Some outcomes change because speed changes alter spacing and splash opportunities: the measured Sunpetal strategy now loses at wave 9, so broader coverage matters there. The unchanged starter still loses at Emerald wave 4; measured Emerald expansion wins at 100 health.

The actual canvas pest drawing code rendered six trait states, including active dash, recovery, poison suppression and reduced motion; the sheet was visually inspected. Browser layout, touch and keyboard checks remain manual because the supported browser-preview capability is unavailable. No preview server or substitute browser automation was started.

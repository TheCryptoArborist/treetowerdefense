# Battlefield command windows

The battlefield has a compact portrait deployment dock and six illustrated command buttons: Defenders, Shop, Harvest, Field guide, Unlocks and Scout. Desktop places the dock left of the map and commands right; on narrow screens commands run above the map and the defender tray scrolls horizontally below it. The long defender grid, shop sidebar and secondary disclosures no longer extend the main game page. Explore the TREE ecosystem remains near the footer.

The existing native `help-dialog` now contains six management sections with labeled navigation and a persistent Back to map button. Desktop uses a centered, dimmed-backdrop window; mobile uses nearly the full viewport with internal scrolling. Escape closes it unless a purchase is active. Native dialog focus containment and return focus are retained. Return-to-deploy sends focus to the battlefield. Readable text accompanies all command art; Scout uses the real beetle painter.

Defenders shows the earned roster, actual guardian portraits, availability and the original numbered-copy selector. Return to map & deploy closes the window without planting or spending. Selecting a planted defender opens Shop with its existing inspector; Shop also lists planted defenders for selecting an individual. Supplies, targeting, styles and upgrade controls are the original DOM controls. Purchase review opens as a second native modal above Shop, preserving all invoice, recovery and wallet controls. NFTree, Sap, TREE prices, upgrade scope and unlock requirements are unchanged.

Simulation and combat effects remain held while the management dialog is open using the existing frame/draw checks. Opening it keeps the running phase internally, so Leaf Storm is eligible for an active wave with enemies. Closing management explicitly pauses a running battle; Resume is a separate player action. Already paused battles, build states and outcomes are not resumed or changed. A busy checkout or open purchase review blocks section changes and closing the underlying management window.

Harvest has an illustrated forest cover, amber/copper buttons and reward cards. Existing event entry and earned cosmetic controls are preserved. Entering the event returns to its fresh battlefield. Field guide contains the existing currency/tactics/instructions; Unlocks contains real earned milestones and the clearly planned Thorn Bastion and Root Obelisk previews. Scout contains the original dynamic next-wave portraits and counters.

# Root Shield force field

Replace the flat oval with a translucent teal/mint energy dome around the
original Tree of Life. Rear aura and ground rim sit behind the tree; a faint
honeycomb surface, slow energy bands, glowing contour and small shield crest
sit in front. The tree artwork remains readable and unchanged. Geometry
grows with the tree and fits within the right battlefield edge.

Shimmer follows the existing visual clock, so it freezes while paused or
management is open. Reduced motion uses fixed geometry. Protection disappears
when shield reaches zero; the existing HUD remains the numeric strength
indicator. Prices, 50-point refill/cap, damage absorption and saved progress
are unchanged. Rendering never edits game state or authorizes purchases.

Visual QA renders the actual production tree and Harvest background using
the same Canvas 2D renderer at forest ranks 0, 2 and 3. These checks cover
tree visibility, label readability, dome proportions and right-edge fit.
Automated rendering checks cover depletion, all tree sizes, balanced canvas
state, immutable inputs, paused-clock stability and reduced motion.

The user confirmed that the shield remained after refresh. Combined with
the independently verified 3,000 TREE receipt, observed applied current-run
purchase and separate older-run entries, the real-wallet recovery test is
accepted. The numeric HUD value was not supplied, so acceptance records
visible post-refresh protection rather than inventing a 50-point reading.
The product's fixed 50-point grant remains covered by engine/ledger tests.
